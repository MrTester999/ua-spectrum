UA SPECTRUM v1.3.0
==================

DESCRIPTION
-----------
UA Spectrum is a Chromium Manifest V3 extension that assigns a network
User-Agent identity to each eligible HTTP(S) tab. It uses session-scoped
declarativeNetRequest rules and includes 9,137 Chrome, Edge, Firefox, and Safari
identities across Windows, Linux, macOS, Android, and iOS.

INSTALLATION
------------
1. Extract dist/ua-spectrum-1.3.0.zip.
2. Open chrome://extensions.
3. Enable Developer mode.
4. Select Load unpacked.
5. Choose the extracted extension folder.
6. Pin UA Spectrum from Chrome's extension menu.

ENABLE OR DISABLE
-----------------
Use the switch in the popup header. Enabling installs rules for every eligible
tab. Disabling removes every UA Spectrum rule, tab assignment, and badge.

ROTATION
--------
Rotate this tab  - Changes the active unlocked tab.
Rotate all tabs - Changes all eligible unlocked tabs in one batch.

Automatic policies:
- Every navigation
- When a tab gains focus
- Stable per tab
- Every 30 seconds
- Every 5 minutes

IDENTITY LOCK
-------------
Press Lock identity to preserve the active tab's identity during navigation,
focus, timed, and all-tab rotation. Unlock it before rotating that tab manually.

SITE EXCLUSIONS
---------------
Press Exclude this site to remove protection from the current hostname. Press
Include this site to restore it. You can also edit one domain per line under
Rotation & targeting.

EXPORT AND IMPORT
-----------------
Export settings downloads a JSON backup containing the enabled state, policy,
browser/platform filters, and excluded domains. It does not include browsing
history or tab assignments.

Import settings validates supported values before applying the configuration.

DASHBOARD
---------
The popup displays status, current identity, User-Agent string, browser,
platform, policy, last-change time, hostname, exclusion status, and all-tab
coverage. Toolbar badges: CH (Chrome), ED (Edge), FF (Firefox), SF (Safari).

PRIVACY
-------
- No telemetry or analytics.
- No remote runtime scripts.
- Preferences use local extension storage.
- Tab assignments and locks use session storage.
- Internal pages and excluded domains are untouched.

IMPORTANT LIMIT
---------------
UA Spectrum changes network request headers. Chromium still controls
navigator.userAgent and other fingerprint surfaces. The extension does not
isolate cookies, storage, IP address, TLS behavior, canvas, WebGL, fonts, or
screen metrics. Use separate browser profiles for stronger isolation.

VERIFICATION
------------
npm run check
npm run smoke

RESPONSIBLE USE
---------------
Use only on systems where you are authorized to test request identity.
